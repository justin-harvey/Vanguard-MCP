# Copyright header convention

Every new source file added on or after the C1 cut-over (see
`AUDITOR-COMMERCIAL-MILESTONES.md` and `CHANGELOG.md`) starts with this header,
in the comment style of its language:

```js
// Copyright (c) 2026 Civic-Chain. All rights reserved.
// Source-available under the Civic-Chain Commercial Licence; see LICENSE.
// Not open source. No redistribution or resale.
```

Do not add the header to files that predate the cut-over commit without
counsel's confirmation of ownership (C1 open item). The header is a convention,
not a substitute for the `LICENSE` file, which is authoritative.
